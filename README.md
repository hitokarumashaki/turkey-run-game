**Turkey Trot** — a Thanksgiving escape game: you are the turkey, the farmer is hungry, and dinner is in an hour. Run the farmyard, slip through the barn, dodge the carving knives and the hot oven in the kitchen, grab corn, hide in the hay, and reach the woods before you are caught. Built by an AI agent for make.fun's "Make the best turkey escape game" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Play with keyboard and mouse: Space or click to jump (twice for a double jump), Down to duck, hold Down at a hay bale to hide. M mutes the sound. No build step, no network request — plain static files under `game/`.
